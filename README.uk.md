mdview — невеликий десктопний застосунок на Go і [Wails](https://wails.io). Markdown перетворюється через
[goldmark](https://github.com/yuin/goldmark) і показується в системному WebView, тож власного браузера
всередині немає: бінарник займає кілька мегабайтів і запускається миттєво. Це саме *переглядач*, а не редактор,
тому інтерфейс навмисно мінімальний.

## Можливості

- **Швидкість і малий розмір**: Go-бекенд і системний WebView (WebView2 / WKWebView / WebKitGTK).
- **GitHub-flavoured Markdown**: таблиці, списки завдань, закреслення, автопосилання, виноски, сирий HTML.
- **Підсвічування синтаксису** в блоках коду (chroma) зі світлою та темною палітрами.
- **Зміст** за заголовками, поточний розділ підсвічується під час прокрутки.
- **Пошук на сторінці** з лічильником збігів і переходом уперед/назад.
- **Історія відкриттів** (останні 50 файлів) у бічній панелі; відсутні файли показуються закресленими.
- **Автооновлення**: сторінка перемальовується, коли файл змінюється на диску, а позиція прокрутки зберігається.
- **Drag-and-drop**: перетягніть файл Markdown у вікно.
- **Один екземпляр**: відкриття іншого `.md` використовує вже запущене вікно.
- **Відносні картинки та посилання працюють**: локальні зображення читаються з диска, посилання на інші `.md` відкриваються всередині mdview, зовнішні — у браузері.
- **Світла / темна / системна тема** через меню або кнопку у верхній панелі.
- **Зберегти як…**: самодостатня HTML-сторінка (стилі, підсвічування й картинки вбудовані; придатна для друку) або копія вихідного тексту.
- **Локалізація**: українська, English, Polski, Deutsch; нова мова — це один JSON-файл.
- **Кросплатформність**: Windows, macOS, Linux з одного коду.

## Початок роботи

### Вимоги

| | |
|---|---|
| Go | 1.21 або новіший |
| Wails CLI | v2 (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`) |
| Windows | WebView2 (є у Windows 10/11 з коробки) |
| macOS | Xcode command line tools (`xcode-select --install`) |
| Linux | `libgtk-3-dev` та `libwebkit2gtk-4.0-dev` (Ubuntu 24.04: `libwebkit2gtk-4.1-dev` і збірка з `-tags webkit2_41`) |

Команда `wails doctor` перевіряє, чи все на місці.

### Збірка з вихідного коду

```bash
git clone https://github.com/<ваш-користувач>/mdview.git
cd mdview
go mod tidy
wails build
```

Результат лежить у `build/bin/` (`mdview.exe` на Windows, `mdview.app` на macOS, `mdview` на Linux).

Режим розробки з гарячим перезавантаженням фронтенду:

```bash
wails dev
```

> Wails використовує нативні бібліотеки, тому збирайте кожну платформу **на ній самій** (або скористайтеся вбудованим CI, див. нижче).

### Корисні варіанти збірки

| Команда | Результат |
|---|---|
| `wails build -clean` | спочатку очищає `build/bin` |
| `wails build -ldflags "-s -w"` | менший бінарник (без debug-інформації) |
| `wails build -ldflags "-X main.Version=1.0.0"` | задає версію у вікні «Про програму» |
| `wails build -nsis` | інсталятор для Windows з асоціацією файлів (потрібен [NSIS](https://nsis.sourceforge.io/)) |
| `wails build -tags webkit2_41` | Linux з WebKitGTK 4.1 (Ubuntu 24.04+) |

### Безперервна інтеграція

`.github/workflows/build.yml` збирає бінарники для Windows, macOS і Linux через матрицю GitHub Actions.
Запуште тег на кшталт `v0.3.0` (або запустіть workflow вручну) і завантажте артефакти на вкладці **Actions**.


## Відкриття `.md` подвійним кліком

mdview отримує шлях до файлу аргументом командного рядка (Windows, Linux) або подією ОС (macOS Finder).

**Windows**
- Найпростіше: правий клік на будь-якому `.md` → *Відкрити за допомогою* → *Вибрати інший застосунок* → `mdview.exe` → *Завжди*.
- Або зберіть інсталятор `wails build -nsis`, він сам зареєструє `.md` і `.markdown`.

**macOS**
Асоціація описана в `wails.json` (`fileAssociations`) і потрапляє в `Info.plist`.
Скопіюйте `mdview.app` у *Програми*, потім на будь-якому `.md` виберіть *Інформація → Відкривати у програмі → Змінити все…*.

**Linux**
```bash
sudo install -m 755 build/bin/mdview /usr/local/bin/mdview
install -Dm 644 build/linux/mdview.desktop ~/.local/share/applications/mdview.desktop
xdg-mime default mdview.desktop text/markdown
```

## Налаштування та дані

Зберігаються в стандартному каталозі конфігурації користувача (`os.UserConfigDir()`):

| ОС | Розташування |
|---|---|
| Windows | `%APPDATA%\mdview\` |
| macOS | `~/Library/Application Support/mdview/` |
| Linux | `~/.config/mdview/` |

| Файл | Вміст |
|---|---|
| `history.json` | нещодавно відкриті файли (до 50) |
| `settings.json` | `language` і `theme` (порожнє значення = як у системі) |

Шлях також показано у вікні «Про програму». Щоб скинути програму, видаліть ці файли.

## Мови

Інтерфейс бере мову системи, а якщо такої немає — англійську. Змінити можна в **Вигляд → Мова**.

Переклади лежать у `locales/<код>.json` і вбудовуються в бінарник. Щоб додати мову:

1. Скопіюйте `locales/en.json` у `locales/<код>.json` (наприклад `fr.json`).
2. Перекладіть значення; у полі `"_name"` вкажіть назву мови її ж мовою (вона з'явиться в меню).
3. Перезберіть програму. Відсутні ключі беруться з англійської.

`go test ./...` перевіряє, що в усіх мовах однаковий набір ключів.

## Налаштування: автор, компанія, версія

| Що | Де |
|---|---|
| Автор, компанія, сайт у «Про програму» | `about.json` |
| Властивості `.exe` (вкладка «Подробиці») та метадані інсталятора | `wails.json` → `author`, `info.companyName`, `info.copyright`, `info.productVersion` |
| Версія у «Про програму» | `-ldflags "-X main.Version=x.y.z"`, значення за замовчуванням — у `lang.go` |

Порожні поля в `about.json` просто не показуються.

## Структура проєкту

```
mdview/
├── main.go            # налаштування Wails, один екземпляр, drag-and-drop, подія відкриття на macOS
├── app.go             # методи для JS, стеження за файлом, обробник локальних картинок
├── render.go          # конвеєр goldmark, переписування посилань і картинок, CSS підсвічування
├── export.go          # «Зберегти як»: експорт у самодостатній HTML
├── history.go         # history.json (атомарний запис)
├── settings.go        # settings.json, каталог конфігурації
├── i18n.go            # вбудовані переклади, визначення мови
├── lang.go            # мова та «Про програму», версія
├── theme.go           # тема, тема рамки вікна, сповіщення
├── menu.go            # нативне меню, перебудовується при зміні мови/теми
├── about.json         # автор / компанія / сайт
├── locales/           # uk.json, en.json, pl.json, de.json
├── frontend/          # звичайні HTML/CSS/JS без збірки
│   ├── index.html
│   ├── style.css
│   └── app.js
├── build/linux/       # .desktop-файл
├── .github/workflows/ # CI для трьох платформ
└── wails.json
```

## Як це працює

- **Рендеринг**: goldmark (GFM, виноски, авто-ID заголовків) і goldmark-highlighting із CSS-класами. Власний AST-трансформер переписує відносні URL картинок на `/_local?p=…`, а посилання на інші Markdown-файли — на `mdview:open?p=…`.
- **Локальні картинки**: невеликий обробник в asset-сервері Wails віддає з диска лише файли зображень.
- **Автооновлення**: `fsnotify` стежить за *каталогом* файлу (редактори часто зберігають через тимчасовий файл і rename) та згладжує серії подій.
- **Теми**: CSS-змінні з `prefers-color-scheme`, перевизначені атрибутом `data-theme="light|dark"` на `<html>`; палітра підсвічування генерується окремо для кожної теми зі стилів chroma (`github` / `github-dark`).
- **Меню та переклади**: рядки беруться з тих самих вбудованих JSON, що й у фронтенді; зміна мови чи теми перебудовує нативне меню й сповіщає інтерфейс подіями Wails.
- **Експорт**: той самий рендерер у режимі «експорт» вбудовує картинки як data-URI (до 8 МБ кожна) і загортає результат у самодостатню сторінку.

## Відомі обмеження

- Сирий HTML усередині Markdown показується як є (`html.WithUnsafe`). Для власних файлів це нормально, але перед відкриттям чужих документів його варто вимкнути в `render.go`.
- Якірні посилання всередині документа на заголовки не латиницею (наприклад `[див.](#заголовок)`) не працюють, бо goldmark генерує ID лише з ASCII. На зміст це не впливає.
- Рамка вікна змінює тему лише на Windows; на macOS і Linux вона йде за системою.
- Вигляд трохи відрізняється між WebView2, WebKit (macOS) і WebKitGTK; перевіряйте CSS на всіх трьох.
- Підтримуються лише локальні відносні ресурси; Mermaid, формул і віддалених вбудовувань поки немає.

## Вирішення проблем

| Повідомлення / симптом | Пояснення |
|---|---|
| `Wails is now using the new Go WebView2Loader` | Інформаційне повідомлення, нічого робити не треба. |
| `Warning: Cannot create installer: makensis not found` | Запущено `-nsis` без встановленого NSIS. Встановіть його (`winget install NSIS.NSIS`) або збирайте без `-nsis`. |
| Linux: збірка падає на `webkit2gtk-4.0` | Встановіть `libwebkit2gtk-4.1-dev` і збирайте з `-tags webkit2_41`. |
| Діалог файлу чи перетягування не працює на дуже старому Wails | Оновіть CLI й виконайте `go get github.com/wailsapp/wails/v2@latest && go mod tidy`. |
